# Kopa Connect — MVP Implementation Plan

Kopa Connect is a mobile-first Progressive Web App (PWA) for Nigerian NYSC Corps Members, following their journey from pre-service through POP. It is built on five core pillars: Camp Experience, People Discovery, Open Social Updates, Jobs & Skills, and Marketplace — with supporting features: Chat, Communities, Events, Profiles, and Notifications.

### Phase 4: Backend API (Vercel Serverless Functions)

All API routes return JSON. Auth routes issue JWTs stored in `localStorage`. All protected routes verify JWT in `Authorization: Bearer <token>` header.

Key API groups:
- **Auth**: Register (3-step), Login (email/phone/state-code), Forgot password
- **Users**: Profile CRUD, discover people, connections
- **Camp**: Dashboard, announcements, camp people, auto-transition logic
- **Feed**: CRUD posts + media, likes, comments, share, report
- **Jobs**: CRUD jobs, search/filter, apply/contact
- **Marketplace**: Vendors + listings CRUD, search
- **Chat**: Conversations + messages (polling MVP)
- **Communities**: CRUD + membership + feed
- **Events**: CRUD events
- **Skills**: List skills, add to profile, search by skill
- **Notifications**: List + mark read
- **Upload**: Vercel Blob presigned URL handler
- **Admin**: Full platform management (super + state-scoped)
